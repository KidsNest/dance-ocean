# おどる水槽 / Dance Ocean

音楽にあわせて、水の中の生きものがおどる育成ゲームです。
A small aquarium game where sea creatures dance to music.

▶ あそぶ / Play: https://kidsnest.github.io/dance-ocean/

- 4さいから、家族でいっしょに / For ages 4+, to play together with family
- スマホ・タブレット向け(タッチ操作) / Made for phones and tablets
- 広告なし、アカウント不要、データを外に送りません / No ads, no account, no data sent anywhere
